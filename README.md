Exclusive — E-Commerce Website
A modern, responsive e-commerce frontend built with HTML, Tailwind CSS v4, and Flowbite.

 Project Overview
Exclusive is a South Asia-based online shopping marketplace UI, featuring a clean and minimal design. The project covers all core pages of a typical e-commerce experience — from product browsing to checkout.

Tech Stack
HTML5
Tailwind CSS v4
Flowbite
Font Awesome
