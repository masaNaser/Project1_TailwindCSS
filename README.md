# 🛍️ Exclusive — E-Commerce Website

A modern, fully responsive e-commerce frontend built with **HTML5**, **Tailwind CSS v4**, and **Flowbite**.

---

## 📌 Project Overview

**Exclusive** is a South Asia-based online shopping marketplace UI featuring a clean, minimal, and user-friendly design.

The project includes all core pages of a complete e-commerce experience — from product browsing and filtering to cart management and checkout.

---

## 🚀 Tech Stack

- **HTML5**
- **Tailwind CSS v4**
- **Flowbite**
- **Font Awesome**

---

## 🎯 Features

- Fully responsive design
- Modern UI layout
- Product listing & product details pages
- Shopping cart interface
- Checkout page design
- Clean and reusable components
